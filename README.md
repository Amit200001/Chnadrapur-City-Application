# Chandrapur City Guide | Black Gold City

An interactive, responsive single-page web application designed to connect residents and tourists with attraction spots, local food hubs, emergency helplines, public transport, and shopping destinations across Chandrapur, Maharashtra.

---

## 🌟 Key Features

* **Interactive Search & Filtering**: Real-time text search across names, descriptions, locations, and tag highlights.


* **Category Tabs**: Easily filter listings by category:
* 🌲 **Tourist & Nature**

* 🍽️ **Saoji & Dining**

* 🚑 **Helpline & Services**

* 🛍️ **Markets & Shopping**

* 🚌 **Transit & Stations**



* **Bookmark & Saved Places**: Save favorite spots locally using browser `localStorage` and view them anytime with the **Saved** filter toggle.


* **Sorting Capabilities**: Sort places by **Featured First**, **Top Rated**, or **Name (A–Z)**.


* **Detailed View Modal**: Inspect comprehensive info including operating hours, entry fee details, contact numbers, address, and Google Maps direction links.


* **Emergency Banner**: Quick access top banner for emergency hotlines (Police, Ambulance, Fire, Municipal Corporation).



---

## 🛠️ Built With

* **HTML5**: Page structure and semantic layout.


* **Tailwind CSS (v3 CDN)**: Responsive design system with custom brand color palette (`brand-terracotta`, `brand-forest`, `brand-gold`, `brand-dark`, `brand-sand`).


* **FontAwesome (v6.4.0)**: Icons for navigation, cards, categories, and actions.


* **Google Fonts**: Modern, readable typography using **Plus Jakarta Sans**.


* **Vanilla JavaScript (ES6+)**: Dynamic DOM manipulation, filtering, sorting, bookmarking, and state management.

## 🚀 Getting Started

Since this project runs entirely client-side without external backend dependencies, setup is straightforward:

1. **Clone the Repository**:
```bash
git clone https://github.com/your-username/chandrapur-city-guide.git
cd chandrapur-city-guide

```


2. **Open in Browser**:
* Double-click `Index.html` to open directly in your web browser.


* Or use a local server like Live Server extension in VS Code:
```bash
npx live-server .

```
